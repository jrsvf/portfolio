Produção agropecuária

Código 
{
  const vaPE = ["agro", "ind", "serv", "adm"].map(k => d3.sum(regs, x => x.pib.va[k] ?? 0));
  const vaR = ["agro", "ind", "serv", "adm"].map(k => r.pib.va[k] ?? 0);
  const ql = vaR.map((v, i) => (v / d3.sum(vaR)) / (vaPE[i] / d3.sum(vaPE)));
  const nomes = ["Agropecuária", "Indústria", "Serviços", "Administração pública"];
  return html`<div class="rx-cc-qls rx-ql-va" title="QL do valor adicionado: peso do setor na região dividido pelo peso em Pernambuco">
    ${nomes.map((n, i) => html`<span class="${ql[i] >= 1 ? "rx-ql-alto" : ""}">QL ${n} <b>${isFinite(ql[i]) ? ql[i].toLocaleString("pt-BR", {maximumFractionDigits: 2, minimumFractionDigits: 2}) : "–"}</b></span>`)}</div>
    ${tabProd((PROD.regioes ?? {})[r.rd], 15, d3.sum(PROD.produtos.valor))}`;
}

Fonte: IBGE, Produção Agrícola Municipal, Pesquisa da Pecuária Municipal e produção da aquicultura, via SIDRA. QL do valor: peso do produto no valor agropecuário do território dividido pelo peso no estado; só com R$ 50 mil ou mais. Rebanhos aparecem em cabeças, sem valor nem QL.
